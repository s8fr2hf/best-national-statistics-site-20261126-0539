StatAtlas — a national statistics site with real published figures for 18 countries and 8 indicators (population, GDP, GDP per capita, life expectancy, unemployment, inflation, CO2 per capita, Internet use), sourced from the World Bank, ILO and the Global Carbon Budget. Browse by country or by indicator, compare countries side by side, and see every number traced to its source and year. Static files, no network requests, works on desktop and phone.
## Run it
```sh
python3 -m http.server 8080 --directory app
```
